# 🚦 Live 15-Minute Trade Signal Dashboard

An automated technical algorithm built in Python that scans for trend reversals using an Exponential Moving Average (EMA) crossover strategy.

## 📈 Assets Tracked
* Gold (`GC=F`)
* Bitcoin (`BTC-USD`)
* NASDAQ 100 (`NQ=F`)
* GER40 (`GDXI.F`)
* Dow Jones 30 (`YM=F`)

## 🛠️ How to Use
1. Launch the app via your Streamlit Cloud link.
2. Select your target asset from the sidebar menu.
3. Analyze the 15-minute candlestick chart for **BUY** (triangle up) and **SELL** (triangle down) signal markers.
